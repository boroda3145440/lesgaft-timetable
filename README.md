# Расписание занятий НГУ им. П. Ф. Лесгафта

Личная версия расписания вуза: группы, преподаватели и **поиск по аудиториям**,
которого нет в официальной публикации. Оформление — по фирменному стилю университета.

**Сайт:** https://boroda3145440.github.io/lesgaft-timetable/

## Как это работает

- Данные берутся из открытого API официальной публикации вуза на mstimetables
  (publicationId `daaaf5b9-665d-44a1-b349-0ebc10ca5441`).
- `fetch_data.py` выгружает группы, преподавателей, аудитории и пары на 4 недели
  вперёд в статические файлы `data/*.json`.
- GitHub Actions (`.github/workflows/update.yml`) запускает выгрузку каждые 3 часа
  и коммитит изменения; GitHub Pages раздаёт сайт из корня ветки `main`.
- Фронтенд — один `index.html` + `style.css` + `app.js`, без сборки и зависимостей.

## Локальный запуск

```bash
uv run python fetch_data.py          # обновить данные (можно --weeks N, --limit N)
uv run python -m http.server 8017    # открыть http://localhost:8017
```
