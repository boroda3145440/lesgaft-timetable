# Расписание занятий НГУ им. П. Ф. Лесгафта

Личная версия расписания вуза: группы, преподаватели и **поиск по аудиториям**,
которого нет в официальной публикации. Оформление — по фирменному стилю университета.

**Сайт:** https://boroda3145440.github.io/lesgaft-timetable/ (по паролю)

## Что умеет

- Три режима: группы, преподаватели, аудитории; виды день / неделя / месяц.
- Одноимённые аудитории «Зал (1)», «Зал (2)» объединены в одну.
- Подсветка пары, которая идёт прямо сейчас; клик по преподавателю или аудитории
  в карточке переключает на их расписание.
- Онлайн-занятия: ссылка «подключиться» прямо из карточки.

## Как это работает

- Данные берутся из открытого API официальной публикации вуза на mstimetables
  (publicationId `daaaf5b9-665d-44a1-b349-0ebc10ca5441`).
- `fetch_data.py` выгружает группы, преподавателей, аудитории и пары на 4 недели
  вперёд и сохраняет их **зашифрованными** (`data/*.json.enc`: gzip + AES-256-GCM,
  ключ из пароля через PBKDF2). Открытых данных в репозитории нет.
- Браузер спрашивает пароль один раз, расшифровывает данные у себя (Web Crypto)
  и запоминает пароль на устройстве. Пароль робот берёт из секрета репозитория
  `TIMETABLE_PASSWORD`.
- GitHub Actions (`.github/workflows/update.yml`) запускает выгрузку каждый час
  с 06:10 до 22:10 по Москве (ночью расписание не меняется) и коммитит данные
  только при реальных изменениях; GitHub Pages раздаёт сайт из корня ветки `main`.
  Обновить вручную: вкладка Actions → «Обновление расписания» → Run workflow.
- Фронтенд — один `index.html` + `style.css` + `app.js`, без сборки и зависимостей.

## Локальный запуск

```bash
pip install cryptography      # один раз
python fetch_data.py          # обновить данные (~7 минут; пароль в .password или --password)
python -m http.server 8017    # открыть http://localhost:8017
```
